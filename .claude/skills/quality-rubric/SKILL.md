# Quality Rubric — 루브릭 기반 품질 채점

## Overview

`RUBRIC.md`(같은 디렉토리)의 기준으로 코드베이스를 채점한다. 핵심 원칙:
**정량은 명령어로만, 정성은 증거 인용으로만 채점한다. 인상 평가 금지.**

인자: `$ARGUMENTS` (`--quant-only` = 계층 1만, `--qual-only` = 계층 2만)

## 단계별 체크리스트 (TodoWrite로 추적)

### 1단계: 준비

- [ ] `RUBRIC.md` 읽기 — 항상 현재 버전 기준으로 채점 (기억으로 채점 금지)
- [ ] 전회 리포트 확인: `.claude/health-reports/*-rubric.md` 최신 파일 — 추이 비교 기준
- [ ] 채점 샘플 고정 (결정론적 선정 — 재현성의 핵심):
  - 최근 30일 변경 상위 3개 모듈: `git log --since="30 days ago" --name-only --pretty="" -- src/ | sort | uniq -c | sort -rn | head -3`
  - 최신 리포트 1부: `ls -t reports/ | head -1`
  - 장애 수정 커밋 3개: `git log --oneline --grep="fix" -10`에서 최신 3개

### 2단계: 정량 채점 (계층 1, 60점)

- [ ] RUBRIC.md의 M1~M17을 순서대로 실행. 각 지표는 **검증 방법 열의 명령어를 실제 실행**하고 출력을 근거로 기록
- [ ] M4(드라이런)는 부수효과 주의: 실행 전 `git status data/`로 캐시 상태 기록, 실행 후 변화가 있으면 복원하고 리포트에 명시
- [ ] 실행 불가 항목(네트워크 차단 등)은 0점이 아니라 **"측정 불가"로 표기**하고 분모에서 제외 — 가능한 척 금지

### 3단계: 정성 채점 (계층 2, 40점)

**차원별 독립 채점** — 후광 효과 방지를 위해 Q1~Q5를 각각 별도의 `quality-scorer` 서브에이전트로 병렬 디스패치한다. 한 에이전트가 여러 차원을 채점하지 않는다.

각 디스패치 프롬프트에 반드시 포함:
1. RUBRIC.md의 해당 차원 전문 (앵커 표 + 채점 절차)
2. 1단계에서 고정한 샘플 (모듈 목록, 리포트 경로, 커밋 해시)
3. 출력 형식: `점수 / 증거 인용 2개 이상 (파일:라인) / 한 줄 판정 근거`

- [ ] 반환된 채점에 증거 인용이 2개 미만이면 **무효 — 재디스패치** (점수만 받아 적지 말 것)
- [ ] 증거가 앵커 서술과 맞지 않으면 (예: "8점"인데 인용된 코드가 6점 앵커에 해당) 점수를 증거에 맞게 조정

### 4단계: 종합 및 리포트 저장

- [ ] 총점 계산 + RUBRIC.md의 등급표로 해석
- [ ] **안전장치 확인**: 정성 2점 차원 존재 여부 (있으면 총점 무관 이슈화 대상)
- [ ] **추이 비교**: 전회 리포트 대비 차원별 변화 (정성 ±2점 이내는 노이즈)
- [ ] `.claude/health-reports/YYYY-MM-DD-rubric.md`에 저장:
  - 총점·등급, 계층별 점수표, 정성 차원별 증거 인용, 전회 대비 추이, 감점 항목 목록
- [ ] 저장 전 `.gitignore`에 `.claude/health-reports/` 포함 확인 (리포트는 커밋 금지)

### 5단계: 후속 연결

- [ ] 등급이 "양호" 이하면: 감점 항목 목록을 **audit-to-issues 스킬의 입력으로 전달** 가능함을 보고
  (이슈 등록은 외부 공개 행위 — 사용자가 명시 요청한 경우에만 진행)
- [ ] project-enhancement-cycle에서 호출된 경우: 점수와 감점 목록을 사이클 종료 조건 판단에 반환

## Common Mistakes

| 실수 | 방지책 |
|------|--------|
| 증거 없는 정성 점수 수용 | 인용 2개 미만 = 무효, 재디스패치 |
| 한 에이전트가 5개 차원 일괄 채점 | 차원당 1 에이전트 — 후광 효과 방지가 분리의 목적 |
| 채점 샘플을 매번 다르게 선정 | 1단계의 고정 규칙만 사용 — 점수 추이가 무의미해짐 |
| 측정 불가를 0점 처리 | "측정 불가" 표기 + 분모 제외 |
| 정성 점수 절대값에 과민 반응 | ±2점은 노이즈 — 추이로만 해석 |
| 드라이런 캐시 오염 방치 | 실행 전후 `git status data/` 대조, 변화 시 복원 |
